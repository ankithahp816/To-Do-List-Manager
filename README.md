# To-Do List

## Project Description

A simple Python command-line To-Do List application that allows users to add, view, complete, and delete tasks.

## Features

- Add new tasks
- View all tasks
- Mark tasks as complete
- Delete tasks
- Display pending and completed status
- Validate task numbers and user input

## How to Run

Open the project folder in a terminal and run:

```bash
python main.py
```

## Menu

```text
1. Add Task
2. View Tasks
3. Mark Task as Complete
4. Delete Task
5. Exit
```

- Python Standard Library
